# Commercial readiness audit � PR-PRICE-10

Base: merged `780263a`; branch `feat/pr-price-10-public-commercial-catalogue`. Audit date: 2026-09-13.

All 63 keys and all intended mappings are preserved. Two narrowly worded native capabilities are publication candidates: client listing/filtering and deliberate lifecycle edits. The other 61 remain internal: 15 IMPLEMENTED and 46 DRAFT. This is not a public launch or provider-readiness certification.

The original 16 IMPLEMENTED dispositions retain their implementation evidence in [commercial-catalogue.md](commercial-catalogue.md). This audit does not downgrade them or mistake them for saleable features. New native publication evidence combines existing SQL permission/access/capacity coverage, client-list/lifecycle unit contracts, and the added real-local-database browser success/reload scenario with existing capacity-denial scenarios. Final execution results and any disqualifying failures are recorded in [verification](pr-price-10-verification.md).

The machine-readable companion contains exactly one record per canonical key. Paths below distinguish related implementation from complete evidence. A missing complete path is recorded as a gap, never inferred from a mockup. Cross-cutting SQL coverage is not claimed as feature-complete browser proof. No P0/P1 is known in the two narrow published operations; inherited client delivery/continuity source-contract failures exclude broader claims and remain disclosed.

## Shared evidence and boundaries

- Permissions: workspace-team/access.ts, canonical SQL RLS and RPC authorization; plan membership never grants a role.
- Access: commercial_access.sql and commercial_access_corrections.sql exercise actual mutations and owner/workspace/client privacy. Recovery allows existing delivery; restricted writes fail; expired owners recover through Billing.
- Capacity: account_capacity.sql and account_capacity_enforcement.sql cover account-scoped admission, lifecycle reductions, reactivation denials, rollback and concurrent last-slot admission.
- Client listing: pt_hub_clients_page scopes canonical clients to owned/shared/assigned access; client list UI supplies loading, error, empty, search and lifecycle states. Unit fetch and SQL-scope contracts cover this query.
- Lifecycle: pt_update_client_lifecycle authorizes delivery writes and persists status/reasons; the dialog validates required reasons, retains failed input and exposes capacity denial. Browser completion is followed by database readback and page reload.
- No external proof: PR-PRICE-05�09 provider scenarios are deterministic. Additional-seat prices remain private. Support forms do not prove service commitments. Analytics computations do not prove saved segments, scheduled reports, team performance or revenue sync.
